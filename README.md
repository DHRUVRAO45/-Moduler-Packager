# Multi Utility Tool

**Author:** Dhruv Rao

## About
A simple Python program that provides different useful utilities in one place.

## Features
- Current Date & Time
- Date Difference
- Stopwatch
- Countdown
- Factorial
- Compound Interest
- Trigonometry
- Circle Area
- Random Number
- Random List
- Random Password
- OTP
- UUID Generator
- File Create, Write, Read and Append
- Python Module Exploration

## Requirements
- Python 3.x
- No external libraries are required.

## How to Run
Save the code as `main.py` and run:

```bash
python main.py
```

Then select an option from the menu.

## Date Format
For Date Difference, enter dates in:

```text
YYYY-MM-DD
```

Example:

```text
First date: 2024-01-15
Second date: 2026-10-08
```
